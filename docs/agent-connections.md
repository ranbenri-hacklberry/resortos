# חיבור סוכן חיצוני

Codex ו־Cursor לא יודעים לשמור טוקן צוות ולא מפעילים אישור מובנה מול ResortOS. אין שרת MCP נוסף. החיבור הוא ה־API הקיים של התפעול, אחרי אישור מנהל.

## מה המנהל רואה

הגדרות ← סוכנים מחוברים. בקשה ממתינה מוצגת כ־«Codex מבקש גישה» או «Cursor מבקש גישה», עם ההרשאות וקוד התאמה בן ארבעה תווים. השם שהסוכן שלח אינו זיהוי. אישור ודחייה דורשים מנהל או מנהל תפעול מחובר. ניתוק מבטל את ההרשאה מיד ומשאיר את יומן הביקורת.

בקשה שלא אושרה פגה אחרי עשר דקות.

## מה מריצים במחשב של הסוכן

```bash
node scripts/resortos-agent.mjs connect --client codex
```

ל־Cursor מחליפים את `--client` ל־`cursor`. ההרשאה נשמרת ב־`~/.config/resortos/agent-connection.json` במצב 0600. היא לא מודפסת ולא נשמרת במאגר.

ברירת המחדל היא `http://100.127.14.15:3001` דרך Tailscale. כתובת HTTPS מותרת. HTTP ציבורי נדחה. אפשר להחליף עם `RESORTOS_BASE_URL`.

קריאה לבדיקה, בלי שינוי סטטוס:

```bash
node scripts/resortos-agent.mjs units
```

מפתח ההצפנה הזמני של האישור נשמר אצל השרת ב־`~/.config/resortos/agent-seal.key`, מחוץ למאגר.
